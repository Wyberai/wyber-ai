================================================================================
                            KNOWN LIMITATIONS
================================================================================

These are by design and don't affect functionality:

1. Rate limiting uses in-memory store (not Redis)
   - Fine for testing/staging
   - For production 10k+ users: switch to Redis

2. Metrics estimation on Railway free plan
   - Free tier doesn't expose detailed metrics
   - Estimates based on deployment status
   - For accurate metrics: upgrade Railway plan

3. No multi-region database support yet
   - Single region per database
   - Future: can add multi-region provisioning

4. Backup/restore partially stubbed
   - Schema ready
   - Endpoints ready
   - Needs Railway backup API integration
