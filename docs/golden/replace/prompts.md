# Golden prompts: Replace-your-SaaS (build each from its analysis; pick the core features)
Library tools (start with these 10): pipedrive.com, hubspot.com, trello.com, airtable.com, calendly.com, mailchimp.com, typeform.com, freshdesk.com, asana.com, notion.so.
Custom domains (not in the library, to test fresh analysis): a local accounting tool the founder pays for; a niche vertical CRM.
For each: pick the 6 to 8 core features, build, import a real sample export where the tool offers one, run the checker, write the acceptance report.
